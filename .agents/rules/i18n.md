# i18n Rules for Little Muslim

Never hardcode user-facing text. Always use t('key') and add the key to ALL locale files.

- Every user-facing string must be referenced via `context.t('key', params: {...})`.
- Every key must be synchronized across:
  1. `locales/{en,bn,hi,it}.json`
  2. `assets/locales/{en,bn,hi,it}.json`
  3. `assets/l10n/app_{en,bn,hi,it}.arb` (with `@key` metadata)
  4. `lib/l10n/static_translations.dart`
- Check with `npm run i18n:check` before completing any changes.
